# BCT Lab

## Blockchain Technology Lab

This repository contains practical experiments and exercises related to Blockchain Technology.

### Objective

To understand the concepts of blockchain, distributed ledger technology, smart contracts, and Hyperledger Fabric.

### Technologies Used

- Hyperledger Fabric
- Docker
- Git
- Linux
- Node.js

### Experiments

1. Setting up Hyperledger Fabric
2. Creating a Fabric test network
3. Creating a channel
4. Deploying chaincode
5. Creating and querying ledger data
6. Performing blockchain transactions
